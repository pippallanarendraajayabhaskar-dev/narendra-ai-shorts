// GOOD TO KNOW

BEFORE YOU RUN IT.

Q. How long does one export take?+
Depends on the source video's length — transcription is the slowest step since it runs locally. Longer videos take longer.
Q. Does it need an internet connection?+
Only to fetch the source video. Transcription and rendering both run on your own machine.
Q. Do I need to keep this tab open?+
Yes — closing it mid-run will interrupt the request to the local server.
Q. Why no watermark?+
Because it's running entirely on your own setup — there's no hosted service branding anything.
